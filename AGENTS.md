# Architecture rules

- Keep sourced medication interaction references in a typed, provenance-bearing reference module; separate reference summaries from clinically reviewed outcome and scoring rules so importing evidence cannot silently authorize clinical outcomes.
- Preserve the generated Cloud client and configuration; repair mismatched bindings through managed connection tools instead of hardcoding replacement credentials or alternate clients.
- Keep versioned encounter answer keys private and derive clinical action credit from authenticated server-timed events; this prevents browser edits from authorizing scores or achievements.
- Share typed clinical contracts between the encounter UI and trusted edge evaluator, and keep AI-generated drafts separate from reviewed case versions; this preserves compatibility without promoting generated clinical content.
