# Current Remix of Medi Guide AI

I want you to build a very beautiful, production-ready and smart AI based RAG chat it that will use the attached file as knowledge base. It should store the knowledge base in a database. When the user asks a question, it should search through the knowledge base for the answer and provide it to the user. It should be extremely accurate and efficient in extracting answers and forming responses. It should be in both mobile and desktop version. Add user authentication, page loaders, crazy animations and icons and bottom navigation. Make it perfect
